# 世界鐵道・四季慢行（3D）總控台 v6.3

| 檔案 | 用途 |
|---|---|
| `index.html` | 總控台：島嶼卡片、搜尋、**匯入更新**、雲端同步、離線快取、單檔下載 |
| `island1.html` | 第一島 v6.3（獨立檔） |
| `seasons_express.html` | 四島合集 v5.16（第二～四島暫時從這裡進：`?route=two/three/four/globe`） |
| `world-manifest.json` | 島嶼卡片內容；`files` 記內建檔的指紋（sha-256 前 32 碼＋大小），總控台靠它判斷內建檔有沒有變 |
| `sw.js` | 離線：外殼 `vrt-world-rail-v6-3`；島嶼檔 `vrt-world-files-v2`（跨版本保留，不會重下） |

## 版本優先順序
1. 雲端版（Paul 在總控台匯入、上傳到行政中心 GAS 的）——所有裝置自動跟上
2. 這台裝置的匯入版（上傳失敗時，列表會顯示「⏳ 待上傳」）
3. 內建版（repo 裡的檔）

## 匯入
- 可以丟整包 `.zip`，或任一島的單一 `.html`（可一次選多個）。檔名含 `island1`～`island9` → 對應那一島；含 `seasons_express` / `world_all` → 四島合集；`world-manifest.json` → 卡片清單。認不出時看 `<title>` 的「第X島」。
- `index.html`、`sw.js` 不能用匯入換（總控台程式由 AI 推 repo）。
- 跟現在一樣的檔不會更新、不會上傳。
- 匯入 `islandN.html` 後，第 N 島卡片會改開這個獨立檔。

## 只傳有變的部分
- 每個檔在瀏覽器裡用「內容切點」切成約 256 KB 的片段（每台裝置切點相同），雲端每片只存一次。
- 上傳：先問雲端缺哪幾片，只傳缺的。下載：先用這台已有的檔湊，只下載缺的片段，組好後整檔比對指紋才換上。
- 內建檔：下載一次留在本機；只有 `world-manifest.json` 的指紋變了才重下那一個檔。
- GAS 端說明：`gas/admin-world-v2.6.0.txt`。

## 版面
- 總控台：最上方一列「四島全覽・六角大環線」（含全部景點總表，依島分列），下面各島兩個一列。
- 島嶼頁桌機版：`sw.js` 送出島嶼頁時會在檔尾附加 `UI_PATCH`（`<style id="vrt-world-ui">`），右側景點導覽與視角按鈕收進「路線」鈕，下方控制列縮短；手機版不變。雲端匯入的新版島嶼檔也會自動套用；總控台「⬇ 下載」存出的單檔也附加同一段。

## 換內建版（AI 做）
覆蓋檔案後，重算 `world-manifest.json` 的 `files`（sha-256 前 32 碼與 bytes）。總控台與島嶼檔的返回鍵指向 `./index.html`。
